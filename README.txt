THE TITAN PROJECT — ANDROID HOME-SCREEN APP
Class 10 CBSE Board Preparation • 2027

WHAT'S INCLUDED
- index.html: the complete Titan Project study planner
- manifest.json: app name, display mode, colors and icon settings
- service-worker.js: offline caching support after the first successful online load
- icon-192.png and icon-512.png: app icons
- DEPLOY_TO_GITHUB_PAGES.txt: step-by-step publishing and installation guide

IMPORTANT
This is an installable Progressive Web App (PWA), not an Android APK. It can appear on your Android home screen and open in its own app-style window. It does not require Play Store installation.

QUICK PATH
1. Publish these files to an HTTPS website (the included GitHub Pages guide explains one free method).
2. On your Android phone, open the published website in Google Chrome.
3. Wait for the page to load, then tap Chrome's ⋮ menu.
4. Choose "Install app" or "Add to Home screen" (the wording can vary by device/browser).
5. Confirm. The Titan Project icon should appear on your home screen.

DATA & OFFLINE NOTES
- Checklist, chapter progress, marks and exam-date data are saved in local browser storage on that device/browser.
- They are not automatically synced to another device. Clearing Chrome/site data can erase saved progress, so keep any important records separately.
- Open the app online at least once so the service worker can cache its files. Offline availability can vary with browser settings and whether the first load completed successfully.
- If you update the hosted files later, reopen the app online to receive the update.

If Chrome doesn't show Install app, confirm the site uses HTTPS, all files are uploaded at the same folder level, and you opened the hosted page in Chrome rather than a file manager preview.
